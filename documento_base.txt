==================================================
6. SISTEMA DE LISTA DE PRESENTES
==================================================

A lista de presentes NÃO será um sistema de e-commerce tradicional.

O site NÃO realizará a venda do produto.

O sistema funcionará como uma lista de presentes/reserva.

Fluxo:

1. Visitante encontra um produto.
2. Clica em "QUERO PRESENTEAR".
3. Abre uma janela/modal.
4. O sistema mostra o produto escolhido.
5. Solicita:
   - Nome
   - E-mail
6. O visitante confirma.
7. O produto passa para o status "RESERVADO".
8. O sistema registra quem ficou responsável pelo presente.
9. O visitante recebe a informação de que o presente foi reservado.
10. O site apresenta o link externo para compra, caso exista.

IMPORTANTE:

A reserva NÃO significa que o produto foi comprado.

Significa apenas:

"Essa pessoa se comprometeu a presentear o casal com esse item."

==================================================
8. EVITAR DUPLICIDADE
==================================================

Essa é uma regra CRÍTICA.

Duas pessoas não podem reservar o mesmo presente simultaneamente.

O backend/banco de dados deve possuir uma proteção real contra concorrência.

Não confiar apenas no frontend.

Exemplo:

Pessoa A e Pessoa B clicam no mesmo produto praticamente ao mesmo tempo.

O sistema deve garantir que somente uma reserva seja concluída.

A segunda pessoa deverá receber uma mensagem como:

"Esse presente acabou de ser reservado por outra pessoa. Mas não se preocupe, ainda existem outros presentes disponíveis."

O produto deve ser atualizado automaticamente.
